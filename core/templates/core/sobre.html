Sobre o Projeto

Este sistema foi desenvolvido como parte da disciplina de **Web III (Django)** na Fatec.

Nosso objetivo foi construir um site completo, com:

  • Cadastro e login de usuários
  • Listagem e detalhes de produtos
  • Sistema de pedidos com controle de estoque
  • Página de contato
  • Painel administrativo (Django Admin)
  • Layout responsivo com tema dark elegante

Todos os dados exibidos são dinâmicos e administráveis via painel Admin.
